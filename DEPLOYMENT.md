# GitHub Pages Deployment

1. Create a GitHub repository such as `cricket-auction-arena`.
2. Upload/push the entire project.
3. Open repository → Settings → Pages.
4. Choose Deploy from a branch.
5. Select the main branch and `/(root)`.
6. Save and wait for GitHub Pages to publish.
7. Open the HTTPS Pages URL on the host phone and friend phones.
8. Test the full multiplayer flow with at least three separate browsers/devices.

The runtime has no Node server, filesystem dependency or localhost-only API. Firebase SDKs are loaded from the official CDN and the app uses relative paths.
